EXPANDING POLYGON FIELD

Instructions: Click to add shapes; up/down arrows change the number of sides space will clear the canvas


An interactive generative system where user clicks spawn polygonal emitters that expand radially over time. Each emitter produces continuously growing regular polygons with a dynamic number of sides, while color oscillations are driven by trigonometric functions. The semi-transparent background creates motion trails, resulting in a layered wave-like propagation of geometric forms.
