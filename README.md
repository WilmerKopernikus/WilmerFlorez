Portfolio profesional de Wilmer Florez: Desarrollador Web, Diseñador Gráfico y Artista Visual.

## 🚀 Características

- ✅ Diseño responsive y mobile-first
- ✅ Multiidioma (Alemán/Inglés con detección automática)
- ✅ Progressive Web App (PWA) - instalable
- ✅ Service Worker con caché inteligente
- ✅ Optimización de rendimiento (~90% más rápido)
- ✅ Funciona offline después de la primera visita
- ✅ Background animado con p5.js

## 📦 Tecnologías

- HTML5, CSS3, JavaScript (Vanilla)
- p5.js (generative art)
- Service Workers (PWA)
- OpenAI API (Tarot interactivo)
- Vercel (deployment)

## 🛠️ Desarrollo

Ver [DEV-GUIDE.md](DEV-GUIDE.md) para instrucciones completas de desarrollo.

### Quick Start

1. **Clonar repositorio:**
   ```bash
   git clone https://github.com/WilmerKopernikus/WilmerFlorez.git
   ```

2. **Servir localmente (necesario para Service Worker):**
   ```bash
   # Opción 1: Live Server (VS Code extension)
   # Opción 2: Python
   python -m http.server 8000
   # Opción 3: Node.js
   npx serve
   ```

3. **Abrir en navegador:**
   ```
   http://localhost:8000
   ```

### Editar estilos/scripts

```bash
# Editar archivos fuente
# styles/*.css
# scripts/*.js

# Regenerar minificados
npm run build
```

## DEUTSCH

Professionelles Portfolio von Wilmer Florez: Webentwickler, Grafikdesigner und visueller Künstler.

## 🎨 Funktionen

- **Mehrsprachigkeit:** Unterstützung für Deutsch und Englisch
- **Interaktive Hintergründe:** Generative Kunst mit p5.js
- **PWA (Progressive Web App):** Offline-Funktionalität und App-Installation
- **Service Workers:** Intelligentes Caching für optimale Leistung
- **Lazy Loading:** Optimierte Bild- und Videoladung
- **WebP-Bilder:** Moderne Bildformate für schnellere Ladezeiten
- **Tarot-Erlebnis:** KI-gestützte Tarot-Lesungen mit OpenAI-Integration
- **Responsive Design:** Anpassung an alle Bildschirmgrößen
- **Kontaktformular:** Direktkommunikation über Formspree

## 🛠️ Verwendete Technologien

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Animationen:** p5.js für generative Hintergründe
- **Build-Tools:** clean-css-cli, terser (Minifizierung)
- **Bildoptimierung:** sharp-cli (WebP-Konvertierung)
- **PWA:** Service Workers, manifest.json
- **Backend:** Vercel Serverless Functions
- **KI-Integration:** OpenAI API für Tarot-Feature
- **Deployment:** Vercel
